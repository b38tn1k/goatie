Display this reference card, then stop:

```
GOATIE — first-time-user UX mode
The question: can a first-time user complete the primary job
with minimal effort and no confusion?

MODE
  /goatie              activate (full)
  /goatie lite         build as asked, name the friction in one line
  /goatie full         ladder enforced: conventions, defaults, one primary action
  /goatie ultra        challenge the screen's existence before styling it
  "stop goatie"        off

THE LADDER (stop at the first rung that holds)
  1. Does the user need to see this at all?
  2. Does a convention already cover it?
  3. Can a default remove the decision?
  4. Can it be one step?
  5. Only then: new UI — next action obvious in 3 seconds.

COMMANDS
  /goatie-review       friction review of a diff (cut/convention/default/
                       hierarchy/silent/trap/blame findings)
  /goatie-audit        whole-app audit, 120-point scorecard
  /goatie-help         this card

NEVER CUT
  loading/success/error states, empty states, undo on destructive
  actions, accessibility basics, validation messages.

Pairs with ponytail: goatie governs what the user sees,
ponytail governs what you build.
```
